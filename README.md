# 🌿 Student Wellness Source

Welcome to the Student Wellness Source! This is a gentle, Scripture-rooted web application designed to give students a quiet corner of the internet to breathe, reflect, and find encouragement. 

*(Note: This is currently a front-end demo project built to practice HTML/CSS/JS and deployment. A more robust version is in the works!)*

**Live Demo:** [Your-Custom-Domain.com](https://your-custom-domain.com) 

## ✨ Features

*   **🏡 Home & Daily Encouragement:** A calming landing page with a rotating daily Bible verse. You can also click on different moods (Anxious, Tired, Hopeful, etc.) to instantly get a verse tailored to how you're feeling.
*   **📖 Verse Library:** A curated collection of verses specifically chosen to offer comfort for anxiety, depression, loneliness, and grief.
*   **🌬️ Relax & Rest:** 
    *   A fully automated **Breathing Buddy** (4-second inhale, hold, and exhale) to help calm your nervous system.
    *   A gentle visual reminder to simply smile.
*   **💗 Self-Love Journal:** A private journaling space where you can pick a prompt, write your thoughts, and save them. 
*   **🆘 Help Link:** A quick link in the navigation bar to FindAHelpline.com for anyone in immediate need of real-world support.

## 🛠️ Tech Stack

This project is intentionally lightweight—no frameworks, no build tools, just the fundamentals:
*   **HTML5** (Semantic structure)
*   **CSS3** (Custom styling with a hand-painted, "oil painting" aesthetic using CSS gradients and blend modes)
*   **Vanilla JavaScript** (DOM manipulation, timers, and `localStorage` for the journal)
*   **Font Awesome** (Icons)
*   **Google Fonts** (Cormorant Garamond)

## 🔒 Privacy Note

The Self-Love Journal uses your browser's `localStorage`. **No data is ever sent to a server or database.** Everything you write stays completely private and local to your device. If you clear your browser data, the entries will be deleted.

## 🚀 Deployment

This site is hosted using **GitHub Pages**. If you are using a free custom domain like **DEVS.LI**, you can route it by adding a `CNAME` record to your repository and pointing the DNS target to your GitHub Pages URL (`username.github.io`).
